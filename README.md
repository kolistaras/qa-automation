# Лабораторна робота № 1

## Розгортання середовища автоматизації тестування

**Дисципліна:** Автоматизація тестування  
**Виконавець:** Колісінський Тарас
**Група:** ІПЗ-2 
**Варіант:** 12

## Мета роботи

Розгорнути середовище автоматизації тестування на основі Node.js і TypeScript, налаштувати Vitest, ESLint і Prettier та розробити перші автоматизовані тести.

## Індивідуальне завдання

Обчислення середнього арифметичного масиву чисел. Якщо масив порожній, функція генерує виняток EMPTY_ARRAY.

## Структура проєкту

- src/average.ts — реалізація функції обчислення середнього арифметичного.
- tests/average.test.ts — автоматизовані тести.
- vitest.config.ts — конфігурація Vitest і покриття коду.
- tsconfig.json — конфігурація TypeScript.
- eslint.config.mjs — налаштування ESLint.
- .prettierrc — налаштування форматування.
- .gitignore — перелік файлів, які Git ігнорує.
- package.json — залежності та команди проєкту.

## Встановлення

Для встановлення залежностей виконайте команду:

    npm install

## Команди запуску

- npm test — запуск тестів.
- npm run test:watch — запуск тестів у режимі спостереження.
- npm run coverage — вимірювання покриття коду.
- npm run lint — перевірка коду ESLint.
- npm run format — форматування коду.

## Результати

Успішно пройшли чотири автоматизовані тести. Покриття інструкцій, гілок, функцій і рядків становить 100%. Перевірка ESLint завершується без помилок.

## Висновок

У ході лабораторної роботи створено проєкт на TypeScript, налаштовано засоби автоматизованого тестування Vitest, лінтер ESLint і форматувальник Prettier. Реалізовано функцію обчислення середнього арифметичного масиву чисел та перевірено її автоматизованими тестами.
